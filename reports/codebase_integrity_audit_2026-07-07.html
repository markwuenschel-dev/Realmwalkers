Codebase Integrity Audit — Realmwalkers

Read-only Repo Audit Swarm · 4 expert lanes merged & scored · 2026-07-07 · Branch main @ afd03a8 · Scoring spine: REPORT-SCORING.md · Analysis only — no code was modified.

1 · Executive summary

Four read-only lanes (deepening seams, graded integrity, blast-radius, verification readiness) swept the Python FastAPI backend (src/dominion, ~29k LOC), the React/TS frontend (frontend/src, 154 files), and the test/CI surface. The picture is a disciplined, well-defended codebase with a small number of concentrated, high-leverage risks — not a repo in drift.

Strong foundations the lanes independently confirmed with evidence:

  • SQL is fully parameterized (zero string-interpolated queries); subprocess uses exec + argv (no shell=True); no sync-blocking calls in async paths; CORS defaults to empty origins.
  • Broad except Exception handlers are overwhelmingly annotated (# noqa: BLE001 + justification + structured logging) — deliberate, not sloppy.
  • The two hardest test dependencies are seamed: Postgres is real in CI with a DOMINION_REQUIRE_DB hard-fail, and the LLM is mocked at one well-known point with orchestration decisions extracted into pure functions.

The risks cluster into five themes:

  1. An ungated cross-language type mirror — frontend/src/desk/api/types.ts hand-redefines ~14 DTOs the OpenAPI codegen now emits, with no drift gate. The single highest-leverage seam (C1).
  2. Duplicated packet-tier domain logic — packet/ vs scene_packet/ fork approval policy, facade depth, and enum families (C3, C4, C5, C11).
  3. Two ~1,500-line god-modules with circular-import shims on the drafting critical path (C2), currently un-provable end-to-end (C16).
  4. Fake-green & drift-blind CI gates — a no-op Playwright e2e gate, diff-scoped pyright, and zero coverage signal (C12, C13, C14).
  5. Two acknowledged-but-open risks — a known-unfixed greenlet_spawn race in the always-on sweeper (C7) and zero API authentication (C6).
