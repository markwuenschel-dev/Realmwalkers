# SceneFidelity Issue lifecycle

SceneFidelity adds `OVERRIDDEN` and `SUPERSEDED` Issue statuses. An Issue becomes `VERIFIED` only when fresh current evaluation passes its hard clause; it becomes `OVERRIDDEN` only through an author-recorded exception; it becomes `SUPERSEDED` only after a newer current eligible Critique materializes a successor Issue. Missing, stale, or incomplete evaluation leaves the old Issue unresolved and creates a separate operational hold. Overrides cancel their human-required task and never inherit to later drafts; superseded Issues reference their successor.
