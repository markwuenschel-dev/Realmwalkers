# SceneFidelity hard-clause coverage

The merged SceneFidelity report emits a Clause Evaluation for every active hard clause, including when an adapter fails or a dependency blocks evaluation. A hard export-required clause is verified only by a current `satisfied` evaluation with positive prose evidence; eligible `lost` results create repair work, while indeterminate, blocked, and failed results create operational holds. Absence of a finding never proves satisfaction or clears an Issue.
