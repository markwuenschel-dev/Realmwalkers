# SceneFidelity decision-ready author UI

ScenePacket, scene review, and Production Run surfaces present decision-ready status, explanation, proposed fix, and next action by default; contract clauses, dependencies, report links, and model provenance remain inspectable on demand. Suggestions are visually distinct from active requirements. The system may prepare mode suggestions, evaluations, repair Issues, surgical fixes, and repair previews automatically, while the author alone activates requirements, accepts prose, and records overrides.
