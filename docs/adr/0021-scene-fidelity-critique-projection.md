# SceneFidelity Critique projection

SceneFidelity uses the existing `Critique` table with `reviewer="scene_fidelity"` as the immutable operational projection of one report finding. Its payload is a strict versioned SceneFidelity schema; the immutable report Artifact remains the complete evidence record. `Critique` gains generic nullable `draft_attempt_id`, `source_artifact_id`, and `finding_signature` fields plus `created_at`. A partial unique index on `(reviewer, source_artifact_id, finding_signature)` protects report-projection idempotency when all values are present, and a partial `(reviewer, draft_attempt_id, created_at)` index supports SceneFidelity triage and UI loading. A dedicated fidelity findings table is deferred unless real query or load pressure proves the established review path insufficient.
