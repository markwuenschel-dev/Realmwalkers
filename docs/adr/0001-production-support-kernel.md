# Production support kernel stays narrow and has no facade shims

Production run orchestration keeps `dominion.workers.production` as the public facade, but shared persistence primitives now live in a sibling support module so sequence, repair, read, and finalization lanes can depend on one lower layer instead of importing facade internals. The support kernel owns only reusable primitives such as event rows, artifact rows, agent-run rows, issue rows, payload hashing, timestamps, latest packet lookup, and summary refresh; higher-level production lifecycle behavior remains in the facade or lane modules. We intentionally do not keep compatibility wrappers for moved underscore helpers in the facade, so repo call sites use the new owner directly and stale private imports break loudly.
